# Why one initiative

All five designs serve one goal: you ask for a song, and the app teaches you
to play it.

They share one note format. The song source (D2) writes it. The lesson maker
(D3) reads it and writes lessons in it. The practice screen (D4) compares
your key presses (D1) with it. If each design made its own format, each step
would need a converter, and errors would hide between the steps.

They also share one risk. If D2 gives wrong notes, D3 makes wrong lessons,
and D4 marks your right key as wrong. So the order puts the risky parts
first, and each design has a small proof before the next one starts.

# Your words

> "can you help me build an Ipad/Iphone app to learn piano. I know almost nothing, but I full 88 keys Yamahar keyboard and I can attach my device to the keyboard. I want to be able to play any song that I request. Basically the very requireemnt is that I ask for a song, the tutorial is created and it teaches me how to play it. Perhaps it tracks my key presses and teaches me that"

Arjun, 24 October 2026, in the Piano project thread.

What we take from it:

- The app is for one person: Arjun. It is not for the App Store at first.
- Arjun is a near beginner. The app must teach the basics too, not only songs.
- The main need is "any song on request". A fixed song list is not enough.
- The keyboard has 88 keys and can connect to the iPad. Key tracking is a
  "perhaps" in the ask, but we treat it as core. Without it, the app can not
  tell you if you played the right key.
- iPad first. iPhone second, because the screen is small to read music next
  to a keyboard.

# Key

| Word | Meaning |
|---|---|
| D1 | Design 1, Keyboard link: the app reads each key you press. |
| D2 | Design 2, Song in: where the notes of a song come from. |
| D3 | Design 3, Lesson maker: turns a full song into easy lessons. |
| D4 | Design 4, Practice and feedback: the screen where you play, and the score. |
| D5 | Design 5, Basics course: first lessons for a near beginner. |
| MIDI | The standard way a keyboard sends "this key, this hard, now" to a device. Also a file type that holds notes. |
| MusicXML | A file type that holds sheet music. |
| Core MIDI | Apple's built-in code that reads MIDI on iPad and iPhone. |
| Web MIDI | The browser version of MIDI. Safari on iPad does not have it. |
| SwiftUI | Apple's tool to build the screens of an app. |
| Wait mode | The app waits until you press the right key, then moves on. |
| AI transcription | A model that listens to a recording and writes down the notes. Example: Basic Pitch from Spotify. |
| TestFlight | Apple's way to install a test app on your own device. |
| Xcode | Apple's app to build iPad and iPhone apps. It runs only on a Mac. |

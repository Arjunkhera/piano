# Who and what

| Who | Does | Does not |
|---|---|---|
| Arjun | Reads a lesson, plays its exercises. | Mark the keys. |
| Basics course (PianoCore) | Holds the seven lessons, the exercises, the pass rule and the gate. | Draw the screen. |
| Wait mode (PianoCore, from D4) | Marks each key press right, late or wrong, and counts the score. | Know about lessons. |
| Staff (PianoCore) | Says where a white key sits on the treble or bass staff, and which ledger lines it needs. | Draw. |
| Progress store (app) | Saves the passed exercises in the user defaults on the iPad. | Send anything off the iPad. |
| Course screens (app) | Show the lessons, the text, the hint and the score. | Change a mark or a pass. |

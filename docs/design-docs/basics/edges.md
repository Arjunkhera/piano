# Edge cases

| Case | What happens |
|---|---|
| A try that does not pass, after a pass | The pass stays. |
| Arjun leaves an exercise before the end | No score, so nothing is saved. |
| Arjun plays a done exercise again | The new score shows. The pass stays. |
| A tap on a shut lesson | Nothing. The row shows a lock. |
| The saved progress can not be read | The course starts from lesson 1. |
| A key comes too early | No mark. Wait mode of D4 marks late keys only. |
| The right key with the wrong finger | Right. The cable does not send the finger. |
| Exercise 1.2 asks for C1 and C8 | Both are on the 88 keys of the P-125. The screen keyboard scrolls. |
| Exercise 1.1 asks for black keys | It is the only exercise with black keys. It does not use the staff. |
| The first step of a timed exercise | It is never late. You start when you are ready. |
| An exercise id changes in a later version | Its saved pass is lost. So an id never changes once it ships. |

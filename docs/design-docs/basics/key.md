# Key

| Word | Meaning |
|---|---|
| D1 to D5 | The five pieces of the piano app, from the requirements design. |
| D2 | Song in: where the notes of a song come from. |
| D4 | Practice and feedback: wait mode and the score. |
| D5 | Basics course: this design. |
| Wait mode | The app stops at each note until you press the right key. |
| Step | The notes that start on the same beat. You press each key of a step. |
| Pass | A score with 90 percent or more right, and in a timed exercise 10 percent or fewer late. |
| Gate | The rule that opens a lesson only after the lesson before it is passed. |
| Timed | An exercise where a late key counts against a pass. Lessons 5 and 7. |
| Hint | What the screen shows for each step: the name and a lit key, the name only, or the staff only. |
| C position | Five fingers on five white keys from C. Right hand: thumb on C4. Left hand: little finger on C3. |
| Finger numbers | 1 is the thumb, 5 is the little finger, on both hands. |
| Staff | The five lines that music is written on. Treble for the right hand, bass for the left. |
| Ledger line | A short line for a note above or below the staff. |
| Step (on a staff) | One line or one space. 0 is the bottom line. |
| C1, C3, C4, C8 | Keys 24, 48, 60 and 108. C4 is middle C. |
| G2, G3, D4, E4, F4, G4 | Keys 43, 55, 62, 64, 65 and 67. A letter names the key, and the number names the octave. |
| US-1 | The story "a near pass is not a pass", in [stories](stories.md). |
| US-2 | The story "the gate opens". |
| US-3 | The story "time counts from lesson 5". |
| US-4 | The story "read a note on the staff". |
| PianoCore | The Swift package that holds the note format, the lesson maker, wait mode and the course. |
| CI | The checks that run on GitHub for each pull request. |
| TestFlight | Apple's way to put a test build of an app on your iPad. |
| P-125 | Arjun's Yamaha keyboard. |

# Goals and non-goals

| | What |
|---|---|
| Goal | Seven lessons, in this order: find middle C, right hand in C position, left hand in C position, note names, beats, the staff, both hands. |
| Goal | Each lesson has a short text and two or three exercises in wait mode. |
| Goal | The hint gets less as you learn: first the name and a lit key, then the name only, then the note on a staff only. |
| Goal | A pass rule for each exercise, and a gate: a lesson opens when you pass the lesson before it. |
| Goal | Your passes stay on the iPad, so the ticks are there the next day. |
| Goal | The first tunes: "Hot Cross Buns", "Mary Had a Little Lamb" and the first line of "Ode to Joy". Each is a folk tune or older than 1900, written in code. |
| Non-goal | Theory in depth: key signatures, scales past five keys, chords. |
| Non-goal | A grade for the finger you used. The cable sends the key, not the finger. The screen shows the finger, but does not check it. |
| Non-goal | A mark for a key that comes too early. Wait mode of D4 marks late keys only. |
| Non-goal | Sound from the iPad. You hear the keyboard. |
| Non-goal | A way to skip the gate. If the gate gets in the way, it is one change in one file. |

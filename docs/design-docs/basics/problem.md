# Problem today

The app has a practice screen and three tunes. But a near beginner does not
know where middle C is, or which finger is 3. The beginner also does not know which
key a note on a staff names. A song lesson asks for all three at once.

Most beginner courses start with the same short path. Examples are the
books of Alfred and Faber. The path is middle C, finger numbers, one
five-finger position, quarter and half notes, then both hands. The research report says a short gated start
like this is what reviewers praise most.

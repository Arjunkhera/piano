# Goals and non-goals

| | What |
|---|---|
| Goal | The app finds the keyboard when you plug in the cable. You do not pick it from a list. |
| Goal | Each key press lights the right key on screen, with its name, in less than 20 milliseconds. |
| Goal | Chords work: three keys at once light three keys. |
| Goal | PianoCore holds the note format for D2 to D5, with tests that run on Linux and on the Mac. |
| Goal | One command on the Mac builds the app and sends it to TestFlight. |
| Non-goal | Songs, lessons or scores. They come in D2 to D4. |
| Non-goal | Bluetooth MIDI. The P-125 needs an extra adapter for it. |
| Non-goal | Sound from the iPad. The P-125 makes its own sound. |

How we know it worked: you install the app from TestFlight, plug in the
cable, and play a C major scale. The screen lights each of the 8 keys and
names it.

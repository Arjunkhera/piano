# Key

| Word | Meaning |
|---|---|
| D1 to D5 | The five pieces of the piano app, from the requirements design. |
| D2 | Song in: where the notes of a song come from. |
| D4 | Practice and feedback: the screen where you play. |
| P-125 | The Yamaha digital piano Arjun most likely owns. |
| USB TO HOST | The square USB port on the back of the P-125. The printer cable fits it. |
| MIDI | The standard way a keyboard sends key presses to a device. |
| Core MIDI | Apple's built-in code that reads MIDI on iPad and iPhone. |
| PianoCore | The Swift package that holds the note format and the MIDI byte reader. |
| KeyEvent | One key on, key off or pedal message, after PianoCore reads it. |
| Running status | A MIDI shortcut: the keyboard leaves out a repeated status byte. |
| Force | How hard a key is pressed, 0 to 127. MIDI calls it velocity. |
| C4 | Middle C, key 60. |
| E4 | The E above middle C, key 64. |
| G4 | The G above middle C, key 67. |
| A0 | The lowest key of an 88-key piano, key 21. |
| C8 | The highest key of an 88-key piano, key 108. |
| XcodeGen | A tool that makes the Xcode project file from a short text file. |
| TestFlight | Apple's way to install a test app on your own device. |
| US-1 | The story "you press middle C". |
| US-2 | The story "you plug in the cable after the app opens". |
| US-3 | The story "you play a chord". |
| CI | The checks that run on GitHub for each pull request. |

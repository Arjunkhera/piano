# Goals and non-goals

| | What |
|---|---|
| Goal | The iPad app imports a MIDI, MusicXML or .mxl file into the shared note format, with a hand on each note. |
| Goal | The importer picks the reader from the bytes of the file, not from its name. |
| Goal | One command on the Mac records what the Mac plays, and writes a MIDI file of the notes. |
| Goal | One script installs the Mac helper and Transkun. |
| Goal | Songs stay on the device and on the Mac. No song file goes into the repo. |
| Non-goal | Lessons or levels from the notes. That is D3. |
| Non-goal | Sheet music on screen. That is D4. |
| Non-goal | Following repeats in a score. The importer plays the score once, as written. |
| Non-goal | Transcription on the iPad itself. Transkun runs on the Mac first. |
| Non-goal | A band recording. Transkun writes good notes from solo piano only. |

How we know it worked: Arjun imports one file on the iPad and sees it in the
song list. Then he records a piano cover on his Mac, sends the MIDI file to
the iPad, and imports it too.

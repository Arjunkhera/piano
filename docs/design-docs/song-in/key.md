# Key

| Word | Meaning |
|---|---|
| D1 to D5 | The five pieces of the piano app, from the requirements design. |
| D2 | Song in: this design. |
| D3 | Lesson maker: makes easy levels from the notes. |
| D4 | Practice and feedback: the screen where you play. |
| Layer 1 | Import a sheet file that exists. |
| Layer 2 | Record what the Mac plays, and let a piano model write the notes. |
| MIDI file | A file of notes with times. Extension .mid. |
| MusicXML | A file of sheet music as text. Extension .musicxml or .xml. |
| .mxl | A MusicXML file in a zip archive. |
| Partwise, timewise | Two layouts of MusicXML: by part, or by bar. |
| SMPTE | A way to count MIDI time in video frames. |
| A0 | The lowest key of an 88-key piano, key 21. |
| C8 | The highest key of an 88-key piano, key 108. |
| Staff | One set of five lines in sheet music. Piano music has two. |
| Transkun | An open piano model that writes notes from a recording. |
| PyTorch | The Python library that Transkun runs on. |
| ScreenCaptureKit | Apple's code that records the screen and the sound of a Mac. |
| piano-listen | The Mac helper of Layer 2. |
| ImportedSong | One song after PianoCore reads it: title, tempo, bars and notes. |
| PianoCore | The Swift package that holds the note format and the readers. |
| US-1 | The story "you import a sheet on the iPad". |
| US-2 | The story "you record a cover on the Mac". |
| CI | The checks that run on GitHub for each pull request. |
| TestFlight | Apple's way to install a test app on your own device. |

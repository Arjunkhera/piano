# Key

| Word | Meaning |
|---|---|
| D1 to D5 | The five pieces of the piano app, from the requirements design. |
| D1 | Keyboard link: reads the keyboard, and holds the note format. |
| D2 | Song in: where the notes of a song come from. |
| D3 | Lesson maker: makes beginner, intermediate and advanced lessons. |
| D4 | Practice and feedback: this design. |
| D5 | Basics course: the first lessons before a song. |
| Wait mode | The song stops at each note until you press the right key. |
| Step | The notes that start on the same beat. You press each key of a step. |
| Part | 4 bars of a lesson. You practise one part at a time. |
| Mark | Right, late or wrong: what wait mode says about one key press. |
| Tip | The one line after the score that says what tempo to try next. |
| Beats per minute | The tempo. At 60, one beat is one second. |
| PianoCore | The Swift package that holds the note format, the lesson maker and wait mode. |
| P-125 | Arjun's Yamaha keyboard. |
| MIDI | The way a keyboard sends each key press to the iPad. |
| Source | One MIDI device that sends key presses, such as the P-125. |
| Virtual source | A MIDI source that an app makes, not a real device. |
| C3, G3, C4, D4, A3 | Keys 48, 55, 60, 62 and 57. C4 is middle C. |
| US-1 | The story "a wrong key, then the right key". |
| US-2 | The story "a chord in an intermediate lesson". |
| US-3 | The story "a late note". |
| CI | The checks that run on GitHub for each pull request. |
| TestFlight | Apple's way to put a test build of an app on your iPad. |
| Xcode | Apple's tool that builds the app on a Mac. |

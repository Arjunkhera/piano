# Goals and non-goals

| | What |
|---|---|
| Goal | Wait mode: the screen lights the next key or chord, and moves on only when you press each key of it. |
| Goal | Each key press gets a mark at once: right (green), late (green, counted as late) or wrong (red). |
| Goal | A score at the end of each part: right notes of all notes, wrong keys, late notes, and one tip on the tempo. |
| Goal | You pick the song, the level (from D3), the part of 4 bars, the hands and the tempo. |
| Goal | The screen shows the next notes by name, so you can read ahead. |
| Goal | Fix the two keyboard findings of the D1 review: keys stay lit when one of two sources goes away, and key order can mix. The app also stops reading virtual sources. |
| Goal | A check builds the iPad app for each pull request, so a broken build shows before the Mac. |
| Non-goal | Play along at full speed, where the song does not wait. A later item. |
| Non-goal | Falling notes or a sheet music view. A later item. The next-notes row comes first. |
| Non-goal | Song import. D2 does that. Until D2 lands, the app has three tunes that are free to use: "Twinkle, Twinkle, Little Star", "Ode to Joy" and the C major scale. They are written in code, not stored as song files. |
| Non-goal | Saved progress across days. A later item. |

# Risks

| Risk | What we do |
|---|---|
| The key finder picks a wrong key, such as the relative minor. | Beginner moves a minor key to A minor, which has the same white keys as C major. So both answers give a white-key lesson. |
| Middle C position folds a wide tune into five keys, so the tune leaps. | The table allows a move by an octave and a split between hands. D5, the basics course, teaches this position first. A later item can pick a better five-key position per song. |
| The beginner left hand plays only tune notes A and B, not a root. | The table allows a silent left hand. A root note per bar can come later, as a choice. |
| D2 changes the note format. | D3 reads only key, start, length and hand. D3 keeps its code in its own files, so a D2 change merges cleanly. |
| No Swift on the cloud machine. | The tests run in GitHub Actions on Linux, and on the Mac. |

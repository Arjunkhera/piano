# Goals and non-goals

| | What |
|---|---|
| Goal | One call makes a lesson at one level from a list of notes. The same notes always give the same lesson. |
| Goal | Each lesson obeys every rule of its level. The level checker proves it on 600 made-up songs in each test run. |
| Goal | A beginner lesson is the tune only, one key at a time, on the beat. It is in middle C position, in C major or A minor, with finger numbers. |
| Goal | An intermediate lesson keeps up to two keys in the right hand, on the eighth-note grid. The left hand plays root and fifth. The key has 3 or fewer sharps or flats. |
| Goal | An advanced lesson keeps the song as written, in its own key. It drops only notes shorter than a 32nd note and chords no hand can hold. |
| Non-goal | Reading MusicXML or MIDI files. D2 does that and gives D3 a list of notes. |
| Non-goal | Showing or grading the lesson. D4 does that. |
| Non-goal | AI arrangement. A later item can let an LLM pick options, such as the left-hand pattern. Code still applies them and checks them. |
| Non-goal | Pedal and tempo. The note format holds no pedal. Tempo is a practice control in D4, not a level rule. |

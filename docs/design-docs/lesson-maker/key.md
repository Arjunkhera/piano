# Key

| Word | Meaning |
|---|---|
| D1 to D5 | The five pieces of the piano app, from the requirements design. |
| D1 | Keyboard link: reads the keyboard, and holds the note format. |
| D2 | Song in: where the notes of a song come from. |
| D3 | Lesson maker: this design. |
| D4 | Practice and feedback: the screen where you play. |
| D5 | Basics course: the first lessons before a song. |
| Master score | Every note of a song at full difficulty, from D2. |
| PianoCore | The Swift package that holds the note format and the lesson maker. |
| Alfred | A piano method publisher. Its levelling guide sets what each level may hold. |
| ABRSM | A UK music exam board. Its sight-reading table sets what each grade may hold. |
| Krumhansl-Kessler | Two lists of numbers that show how much each note belongs to a major or a minor key. |
| Pitch class | A note name with no octave: all C keys are pitch class 0. |
| Middle C position | Right thumb on C4, left thumb near it: the first hand position in most methods. |
| C4 | Middle C, key 60. |
| A3, B3, F3 | The keys 57, 59 and 53, below middle C. |
| G4 | Key 67, the top of the beginner right hand. |
| Root and fifth | The bottom note of a chord, and the note 7 keys above it. |
| 5th, octave, 9th | A reach of 7, 12 and 14 keys. |
| Breach | One place where a lesson breaks a rule of its level. |
| US-1 | The story "a beginner lesson of a song in D major". |
| US-2 | The story "an intermediate lesson of a song in E major". |
| US-3 | The story "the checker finds a bug". |
| CI | The checks that run on GitHub for each pull request. |
| LLM | A large language model, such as Claude. |
| JSON | A plain text format for data. |

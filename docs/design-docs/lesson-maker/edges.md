# Edge cases

| Case | What happens |
|---|---|
| An empty score | Each lesson is empty. The key is C major and the move is 0. |
| A note with no length, a start before 0, or a key off the piano | The maker drops it. |
| A score with only left-hand notes | Beginner and intermediate take the tune from all notes. |
| Two notes on the same beat after the snap | The top key wins (beginner). The right hand keeps the top two (intermediate). |
| A held note and a new chord too wide for one hand | The held note ends where the chord starts. |
| A right hand so low that the left hand cannot fit below it | The intermediate left hand drops the fifth, then the root, for that bar. |
| A move would push a key off the piano | The key moves by an octave back onto the piano. |
| 3 beats in a bar | Beginner notes end at the bar line, so no note is longer than 3 beats. |
| A minor song | Beginner moves it to A minor. G sharp becomes G. |
